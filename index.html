07

Bases, Dimension & Rank

Bases · Dimension · Coordinate Systems · Rank · Rank-Nullity Theorem

Key Concepts

  • Basis: linearly independent spanning set
  • Dimension = number of vectors in any basis
  • Coordinate vector [v]_B
  • Rank = dim(Col A); Nullity = dim(Nul A)
  • Rank + Nullity = n (Rank-Nullity Theorem)
  • W ⊂ ℝ⁴ defined by constraints → basis and dimension
Lay et al., 5th ed. §4.3, §4.4, §4.5, §4.6
